Provena · 18 · Counted on the 0.17.0 build · github.com/Pianonurmi/goo-ets-etrm

Every number on this slide comes from the build itself: 489 backend tests including the end-to-end business scenarios and a test that drives every API operation as a minimal-role user, 454 component and page tests for the web UI, and 89 Playwright journeys that create their own data, so the whole suite runs twice on one database, that drive the real application in a browser with accessibility and content-security checks. A check in the build fails when an API operation has no screen and no recorded reason. To try it, use the public demo with a guided tour, or run the same image yourself from ops/demo with Docker Compose. Close with the demo URL and the repository.
