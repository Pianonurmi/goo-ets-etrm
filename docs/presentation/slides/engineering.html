Every number on this slide comes from the build itself: 334 backend tests including the end-to-end business scenarios, 296 component tests for the web UI, and 82 Playwright journeys that drive the real application in a browser with accessibility and content-security checks. A check in the build fails when an API operation has no screen and no recorded reason.
